Treat `prompts/PHASED_COPILOT_PROMPTS.md` only as the current v0.1.1 and v0.2.0–v1.0.0 roadmap map; do not use it to generate a Phase 0 plan or as authorization to start a milestone. Preserve IPSP as the product identity, dataset/domain neutrality, deterministic and evidence authority, security/privacy/licensing, responsible refusal, and the SQLite-control/source-and-Parquet-analytical separation. If the assigned request conflicts with the current gate or a frozen contract, stop and report the exact required authority change rather than guessing.
