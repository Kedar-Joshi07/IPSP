# Reference Material

`Campaign_simulator_UI.html` is copied here as the **canonical visual design reference** for the product.

Use its theme, styling, structure, component feel, and five-step interaction patterns. Do **not** copy its fixed marketing fields, budget/channel assumptions, hardcoded KPI values, fake Monte Carlo progress, FAISS/XGBoost references, or static charts into generic production logic.

Benchmark datasets are intentionally not bundled into this lightweight specification pack. Their roles are documented in `docs/39_BENCHMARK_CATALOG.md`.
