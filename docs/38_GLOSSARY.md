# Glossary

**Capability** — A supportable analytical/predictive/simulation function discovered for a dataset.  
**Dataset Semantic Manifest** — Versioned contract describing grain, fields, semantics, relationships, constraints, KPIs, capabilities, and provenance.  
**Control plane** — SQLite metadata/knowledge/governance state.  
**Analytical data plane** — Source/Parquet datasets used for computation.  
**Champion/Challenger** — Controlled model lifecycle where candidates compete before promotion.  
**Prediction horizon** — When a prediction is made relative to feature/outcome availability.  
**Feature lineage** — How a feature is derived/transformed/aggregated from other data.  
**Intrinsic constraint** — Mathematically unavoidable validity rule.  
**Business constraint** — Explicit process/business rule, not universal mathematical truth.  
**Attribution** — Assignment under a declared rule; not proof of causal effect.  
**Look-alike** — Similarity to a seed cohort; distinct from calibrated response propensity.  
**Trust Score** — Evidence-based decomposition of data/semantic/model/support/drift/constraint/governance reliability.
