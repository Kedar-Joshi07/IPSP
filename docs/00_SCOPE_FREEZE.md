# IPSP v1.0 Scope Freeze

This document freezes the architectural scope before implementation.

## Product boundary

IPSP v1.0 is a **structured-data understanding, predictive modelling, what-if simulation, validation, and explanation platform**. It is not a universal document AI system and not a domain-specific marketing simulator.

### In scope

- Projects/workspaces
- Admin and User roles backed by granular permissions
- Dataset-level permissions plus architecture/basic enforcement for column-sensitive policy
- Structured uploads: CSV/TSV, XLSX, Parquet, JSON/JSONL, supported archives
- Secure staging/quarantine and file validation
- Dataset versioning and sampling/provenance metadata
- Single-table and basic multi-table data understanding
- Grain/key/entity/dimension/measure/time/unit/hierarchy/relationship inference
- Semantic conflict and clarification workflow
- Feature lineage and derived-field detection
- KPI/metric dependency proposals and validation
- Capability discovery and responsible refusal
- Regression, classification, count prediction, forecasting candidates, similarity/look-alike, diagnostic opportunities where supported
- Deterministic what-if and benchmark scenarios
- Monte Carlo uncertainty where valid
- SDV contextual/synthetic simulation where valid
- Model registry and champion/challenger foundation
- Local/remote/hybrid/no-LLM modes
- Trust & Validation Engine
- Simulation history, re-run, reproduce, compare
- PDF and Excel exports
- Detailed audit/security/application/data/ML/LLM/simulation/export/error logging
- Dark + light UI derived from the supplied HTML design
- Background job abstraction
- Feature flags, system health, basic backup/restore

### Architecture-ready but not full v1 functionality

- MFA and enterprise SSO
- LDAP/AD
- PostgreSQL
- Distributed workers / Redis / Celery
- Fully automatic model promotion
- Scheduled retraining
- Advanced RAG/fine-tuning
- Full causal inference engine
- Mathematical optimization engine
- External business connectors
- Slack/Teams/email/webhook notifications
- Enterprise vault integrations
- Multi-node deployment

### Out of scope

- Treating PDFs/audio/images/unstructured corpora as primary analytical datasets
- Guaranteeing causal effects from observational data
- Unlimited autonomous schema joining without user review
- Arbitrary executable code generated by LLMs against raw datasets

## Anti-contamination rule

No source dataset, benchmark, demonstration UI, or previous simulator may introduce hardcoded domain fields, KPIs, stages, models, controls, or outputs into the IPSP core.

Benchmark-specific knowledge belongs only in fixtures, expected benchmark manifests, or benchmark documentation.

## 500-row benchmark clarification

Several uploaded 500-row workbooks are **random subsets of their individual larger datasets**. They are suitable for schema/semantic/architecture testing but not for concluding full-population sample size, class balance, seasonality strength, modelling sufficiency, or rare-category prevalence.
